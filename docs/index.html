DSH飞书Session控制

让每个飞书聊天连接一个可控的 DSH session：Web 会话默认独立，飞书按需连接，半衔接与完整衔接可随时切换。

本项目是 PlutoKeating/dsh-lark-bot （AGPL-3.0）的 fork，由见川维护。当前仓库： jason-namehard/dsh-feishu-session-control。

核心行为

  • Web 创建 session 默认不连接飞书。
  • 飞书首次普通消息自动创建独立 session，并使用半衔接。
  • /use 切换已有 session，不回填历史。
  • /switch 选择半衔接或完整衔接。
  • /detach 解除飞书连接，但保留 DSH session。
  • /delete 进入回收站；/purge 二次确认后永久删除。
  • 插件只镜像 DSH 原生审批，Web 或飞书任一端批准即可。
  • DSH 停止后飞书同步断开；没有 Guardian、离线接管或自动重启。

安装

git clone https://github.com/jason-namehard/dsh-feishu-session-control.git
cd dsh-feishu-session-control
pnpm install
pnpm build
node bin/dsh-lark-bot.mjs setup --profile dsh-lark --package file:/absolute/path/to/dsh-feishu-session-control
dsh --profile web

当前 fork 尚未以独立 npm 包发布；不要使用 npx dsh-lark-bot@latest，该名称指向上游项目。

主要命令

/sessions /new /use /switch /detach /rename /delete /purge /mention
