# 核心功能

## Web 会话默认独立

Web/TUI 创建的 session 不会自动连接飞书，也不会把消息、回复或审批推送到飞书。

## 飞书首次消息自动建会话

每个飞书私聊或普通群聊首次发送普通消息时，插件创建一个独立 DSH session，并默认使用半衔接。
只把新消息事件交给 DSH，不会每轮重新注入飞书聊天历史。

## 半衔接与完整衔接

- **半衔接**：只把飞书发起回合的最终结果返回飞书；电脑端独立新回合不抄送。
- **完整衔接**：同 session 中 Web/TUI 发起的新消息和回复也抄送到当前飞书聊天。

使用 `/switch` 的卡片切换。`/use` 切换 session 后默认回到半衔接。

## 跨工作空间 Session 管理

`/sessions` 跨工作空间列出稳定 `MMDD-N` 别名、DSH 标题、状态和当前聊天标记。支持 `/new`、`/use`、
`/rename`、`/detach`、`/delete` 与 `/purge`。

`/delete` 把 session 放入回收站；`/purge` 二次确认后永久删除。删除不会重排其他别名。

## Web 会话管理面板

Web UI 内提供独立但集成的管理面板，可查看活跃、归档和回收站 session；只有回收站项目显示永久删除。

## 原生审批镜像

插件不创建逐工具权限门。只有 DSH 自身发出原生审批时，才把同一请求同步到飞书；Web 或飞书任一端批准
即可继续。飞书采用“正文列完整选项 + 短按钮”的手机友好布局。

## 群聊策略

普通群聊默认整群共用一个 session。`/mention on|off|default` 可按群控制是否必须 `@` 机器人。

## 飞书长连接

消息通过飞书 WebSocket 事件流收发，不需要公网 IP、域名或内网穿透。关闭 DSH 后连接同步断开，不存在
Guardian、自动接管、自动启动或自动重启。
